When you need more than one pick — groups, running order, and duplicates

Picking one name and settling an order are different problems. Mixing them up quietly breaks the odds.

한국어 English 日本語

Most draw tools assume you want one name. What people actually need is usually a result spread over several picks — splitting into groups, setting a running order, rotating a chore. Those are not the same problem, and conflating them quietly breaks the odds.

One pick and many picks are different problems

The difference is whether a name goes back in the pot.

  • With replacement — everyone is a candidate every time, and the same person can come up twice in a row. Drawing "who buys coffee today" each morning works this way.
  • Without replacement — whoever comes up is removed. Running order, chore rotation and group splits are all this kind.

The second is far more common, yet tools usually only support the first. So people draw, delete, and draw again, and mistakes creep in along the way.

Drawing without repeats

Picking one at a time and removing them is tedious, but worse than that, it is easy to get wrong. Forget one deletion and somebody gets picked twice, which you notice after the fact.

Race Roulette sidesteps this structurally: one race produces the whole order. First to last comes out in a single run, so repeats cannot happen and there is nothing to re-draw.

That changes how you use it.

  • Running order — the finishing order is the order.
  • Chore rotation — work down the finishing order and repeat.
  • Picking one person — read first place and ignore the rest.
  • Forfeits — read last place. It also keeps everyone watching to the end.

Splitting into groups

With an order in hand, splitting follows directly. Two methods, and they behave differently.

Straight split — for eight people in two groups, first through fourth in A, fifth through eighth in B. If the draw was random, this carries no bias. It is simple and easy to count.

Snake split — first to A, second to B, third to B, fourth to A, fifth to A, and so on, weaving back and forth. This is what you use when the order carries meaning such as skill. The order here is random, so it is not strictly needed, but in situations where people read the order as a ranking, such as picking teams, the snake feels fairer.

Decide which one before you run it. Choosing the method after seeing the result is no longer a draw.

More than twelve people

This tool holds two to twelve runners per race; beyond that you cannot tell who is who on screen. For larger groups there are two approaches.

  • Split first — with twenty people, divide them arbitrarily into two races, run each, and join the two orders. If the split itself is random, the whole thing is random.
  • Heats and a final — run groups, then race the winners against each other. This one is not uniform: whoever sat in the smaller heat had better odds. Fine for fun, but do not use it where fairness matters.

If you need one person out of twenty, joining the heat winners is the wrong shape. Any method that treats all twenty at once is correct, and unequal heat sizes skew the odds by exactly that much.

Where weights get slippery across many picks

Draw a full order with weights applied and the weights map exactly onto the chance of finishing first. The chances of second and third are more involved — they are the distribution after first place is removed, so they are not a simple proportion.

In practice:

  • If you only read first place, weights behave exactly as stated: a weight of 3 out of a total of 12 is 25%.
  • If you use the whole order, it is easier to explain with no weights at all. Otherwise "why did the person on weight 3 come fifth?" turns into a conversation about conditional probability.

Avoid a weight of zero here too. Zero does not mean "less likely", it means "can never come first". If someone should be out, take them off the list.

Duplicate names

Two people with the same name is fine; the tool does not use names as identifiers, so both run independently. The problem is that you cannot tell them apart in the result, so label them, "Sam K" and "Sam R" or similar. Names take up to ten characters.

Keeping the result

There is no save feature. Refreshing clears the names and the result, and there is no way to replay a race — pressing again re-draws from scratch.

If you need a record, screenshot the results board. This matters more with multi-pick draws than single ones: with groups and rotations, somebody will eventually ask what position they were in, and without a screenshot the only option is re-running, which destroys the meaning of the first result.

Setting the rules before you start remains the thing that matters most. That is covered separately in how to run a draw people will accept.
